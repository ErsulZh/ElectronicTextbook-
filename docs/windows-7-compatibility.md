# Совместимость с Windows 7

## Что поддерживается

Для Windows 7 добавлены отдельные `install-win7.bat` и `start-win7.bat`. Они не меняют современный путь запуска (`install-site.bat` и `start-site.bat`) и используют изолированную папку `win7-runtime`.

`install-win7.bat` требует Node.js 13.6 или новее, устанавливает зависимости по lock-файлу формата npm 6 и проверяет сервер. `start-win7.bat` автоматически вызывает установщик, если совместимые зависимости ещё не установлены.

Сервер в этом режиме берёт парсеры и `PageFlip` только из `win7-runtime/node_modules`, а PDF.js отдаёт в legacy-варианте. Поэтому современный PDF.js и Node.js 22-путь остаются без изменений.

## Ограничения и безопасность

- Windows 7 больше не поддерживается Microsoft, а официальная поддержка Windows 7 в Node.js была прекращена. Node.js 13.6 и старые браузеры также EOL.
- Это best-effort режим для локального чтения. Сервер намеренно привязан только к `127.0.0.1`; не открывайте его в локальную сеть и не используйте старый браузер для сайтов в интернете.
- Нужен браузер с поддержкой ES-модулей. Internet Explorer и классический Edge не подойдут.
- PDF.js в legacy-режиме сохранён ради совместимости с замороженными браузерами Windows 7. Современный путь использует актуальную версию PDF.js.
- Из-за ограничения `MAX_PATH` Windows 7 проект лучше распаковывать в короткий путь, например `C:\Textbook`.

## Порядок запуска

1. Установите совместимую с Windows 7 сборку Node.js 13.6+; официальный архив [Node.js 13.6.0](https://nodejs.org/en/download/archive/v13.6.0) содержит варианты x86 и x64.
2. Распакуйте весь архив проекта.
3. Запустите `install-win7.bat` и дождитесь сообщения о готовности.
4. Запускайте `start-win7.bat`; не закрывайте окно командной строки во время чтения.

Если Microsoft Word установлен, Word-документы сохраняют исходную постраничную разметку через локальное преобразование в PDF. Без Word остаётся адаптированный режим там, где формат это допускает.

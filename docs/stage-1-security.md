# Этап 1 — безопасность и стабильность импорта

Статус: готов к независимой приёмке.

## Выполненные изменения

1. `pdfjs-dist` закреплён на безопасной версии `6.5.438`; `npm audit --omit=dev` теперь сообщает `0` уязвимостей.
2. Каждый импорт требует токен локального сеанса. Запросы без токена, а также запросы с чужим `Origin`, отклоняются с HTTP 403.
3. Добавлены CSP и security headers. Сайт разрешает ресурсы только из собственного `127.0.0.1`-сервера; у импортированного HTML удаляются внешние `src`, `srcset` и `href`.
4. Проверяется сигнатура PDF, OOXML/ODT/EPUB, старого Word и RTF до обработки.
5. Введены лимиты: 250 МБ на файл, 750 МБ на одновременно хранимые файлы, не более 10 открытых книг и 2 параллельных импортов.
6. Добавлены явное освобождение предыдущей книги в браузере, очистка по TTL (30 минут) и корректное асинхронное удаление при остановке сервера.
7. ODT и EPUB получают ограничение на число архивных записей и заявленный распакованный размер.

## Ограничения, не закрытые этим этапом

- Существующие 68 временных папок остались от старой версии до внедрения очистки; новый код не может безопасно удалять чужие/старые каталоги без идентификации владельца.
- Качество содержания, пагинации, EPUB/ODT, UI ошибок и запуска BAT относится к следующим этапам.
- Browser-приёмка выбора файла и перелистывания остаётся обязательной задачей этапов 3, 4 и 6.

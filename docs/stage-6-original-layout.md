# Этап 6 — точная вёрстка Word и книжный разворот

## Что изменено

- Файлы Word (`DOCX`, `DOCM`, `DOTX`, старые `DOC`/`DOT`/`DOCB`, `RTF`) при наличии Microsoft Word сохраняются локально в PDF через Word. Макросы отключены ещё до открытия файла.
- Каждый лист экспортированного PDF становится одним листом электронной книги. Шрифт, формулы, таблицы, изображения, переносы и номера страниц не пересобираются браузером.
- Для такого документа канва PDF лежит на тёплом книжном фоне без дополнительного номера в интерфейсе: номер остаётся тем, который есть в оригинальном документе.
- На широком экране `PageFlip` работает в развороте из двух страниц. Размер одного листа имеет пропорцию A-серии (примерно `1 : √2`), разворот использует почти всю доступную высоту, а центральный сгиб показывает границу между листами. На узком экране остаётся один лист.
- Нижнее поле у HTML-режима увеличено: текст останавливается выше номера страницы. У PDF-режима это поле и положение текста полностью задаёт исходный документ.
- В режиме чтения нет постоянных верхней панели, нижних стрелок и счётчика: книга получает максимум места. Разворот листается жестом, кликом по листу или стрелками клавиатуры; переход из содержания показывает нужный лист на левой или правой половине разворота.

## Поведение при недоступном Word

Если Microsoft Word не установлен или конкретный файл невозможно экспортировать, сайт не застревает на загрузке: он возвращается к прежнему адаптированному HTML-виду и показывает уведомление. Для экспорта PDF установлен конечный лимит 180 секунд; после него пользователь получает обычную ошибку, а не бесконечный индикатор.

## Ограничения

- Точный режим сознательно не удаляет реальные пустые страницы и не исправляет поля исходного Word-файла: это нарушило бы правило «одна страница Word — один лист книги».
- В точном Word-режиме автоматическое содержание берётся только из напечатанного блока после «Мазмұны» / «Содержание» / «Оглавление» / «Contents» / `Table of contents`. Оно объединяет перенесённые строки и соседние страницы списка, но завершает чтение на «Кіріспе» / «Введение» / `Introduction`, начале главы, большом вертикальном промежутке перед обычным текстом либо на странице без строк содержания. Поэтому разрыв листа сам по себе не становится темой. PDF bookmarks Word сознательно не используются: Word часто записывает туда автора, УДК и ISBN. Если надёжный напечатанный список не найден, остаётся только «Начало документа» — случайный текст в меню не добавляется.
- Точность соответствует движку Microsoft Word на этом компьютере; она не является обещанием идентичного рендеринга в другой версии Word или на другом принтере.

## Приёмка

Выполнено локально:

```powershell
npm run check
npm run test:formats
npm run test:reader
```

`test:reader` открыл пользовательский `Казакша электр аппараттары КІТАП 27.10.docx` в точном режиме: 107 исходных PDF-страниц, 46 пунктов напечатанного содержания, 0 внутренних переполнений; он отдельно проверяет, что в меню нет Махамбаевой, УДК, ISBN и библиографической строки. Также проверяются развороты, мобильный режим и 99-страничный PDF. Ручная проверка старого `Казакша электр аппараттары КІТАП 27.10.doc` подтвердила список от «КІРІСПЕ» до «ҚОСЫМША» без титульных данных.

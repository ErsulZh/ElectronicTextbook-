# Этап 6 — точная вёрстка Word и книжный разворот

## Что изменено

- Файлы Word (`DOCX`, `DOCM`, `DOTX`, старые `DOC`/`DOT`/`DOCB`, `RTF`) при наличии Microsoft Word сохраняются локально в PDF через Word. Макросы отключены ещё до открытия файла.
- Каждый лист экспортированного PDF становится одним листом электронной книги. Шрифт, формулы, таблицы, изображения, переносы и номера страниц не пересобираются браузером.
- Для такого документа канва PDF лежит на тёплом книжном фоне без дополнительного номера в интерфейсе: номер остаётся тем, который есть в оригинальном документе.
- На широком экране `PageFlip` работает в развороте из двух страниц. Размер одного листа имеет пропорцию A-серии (примерно `1 : √2`), а сам разворот занимает больше доступной высоты. На узком экране остаётся один лист.
- Нижнее поле у HTML-режима увеличено: текст останавливается выше номера страницы. У PDF-режима это поле и положение текста полностью задаёт исходный документ.
- Счётчик в развороте показывает обе видимые страницы, например `1–2 / 107`; переход из содержания считается успешным, если нужный лист виден на левой или правой половине разворота.

## Поведение при недоступном Word

Если Microsoft Word не установлен или конкретный файл невозможно экспортировать, сайт не застревает на загрузке: он возвращается к прежнему адаптированному HTML-виду и показывает уведомление. Для экспорта PDF установлен конечный лимит 180 секунд; после него пользователь получает обычную ошибку, а не бесконечный индикатор.

## Ограничения

- Точный режим сознательно не удаляет реальные пустые страницы и не исправляет поля исходного Word-файла: это нарушило бы правило «одна страница Word — один лист книги».
- Автоматическое содержание использует bookmarks PDF, а если их нет — заголовки, найденные при безопасном разборе исходного Word. Документ без настоящих или распознаваемых заголовков остаётся с пунктом «Начало документа» и ручным переходом по номеру страницы.
- Точность соответствует движку Microsoft Word на этом компьютере; она не является обещанием идентичного рендеринга в другой версии Word или на другом принтере.

## Приёмка

Выполнено локально:

```powershell
npm run check
npm run test:formats
npm run test:reader
```

`test:reader` открыл пользовательский `Казакша электр аппараттары КІТАП 27.10.docx` в точном режиме: 107 исходных PDF-страниц, 5 пунктов содержания, 0 внутренних переполнений; также проверил развороты, мобильный режим и 99-страничный PDF. Отдельная ручная проверка `Лекция 1.docx` показала на desktop сразу два видимых листа `388 × 548` без горизонтальной прокрутки.

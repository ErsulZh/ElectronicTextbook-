## Обязательные, но пока отсутствующие образцы

| Формат/сценарий | Что необходимо проверить | Статус |
|---|---|---|
| DOCX: длинный текст, список, таблица, изображение | Сохранение форматирования при пагинации | Нет эталонного образца |
| PDF с bookmarks | Переходы по встроенному содержанию | Нет образца |
| PDF без bookmarks | Автоматическое содержание и ручной переход | Нет образца |
| TXT UTF-8 и Windows-1251 | Корректная кодировка | Нет образца |
| Markdown | Заголовки, список, выделение, ссылка | Нет образца |
| HTML с внешней картинкой и опасной разметкой | Изоляция и отсутствие сетевого запроса | Требуется тест этапа 1 |
| ODT | Таблицы, списки, изображения | Нет образца |
| EPUB | Главы, изображения, содержание | Нет образца |
| RTF, DOCM, DOCB, DOT, DOTX, DOTM | Реальная поддержка и зависимость от Word | Нет образцов |

## Стандарт регрессии

Перед приёмкой каждого этапа повторяются: `npm run check`, API-проверка пустого/неподдерживаемого файла и все применимые строки этой матрицы. Визуальные сценарии принимаются отдельно только после browser-тестов.

## Автоматически создаваемые образцы этапа 2

`npm run test:formats` создаёт временные ODT и EPUB и проверяет форматную модель, Markdown, TXT в Windows-1251 и UTF-16LE, а также ветку «Microsoft Word отсутствует». Эти fixtures описаны в коде теста и не содержат пользовательских данных.

## Автоматические образцы этапа 3

`npm run test:reader` использует два открытых HTML-fixture из `fixtures/`: напечатанное содержание и форматирование/список/таблицу. Затем он открывает большой DOCX пользователя локально, проверяет страницу за страницей отсутствие внутренней прокрутки, несколько переходов TOC и мобильную ширину 390 px. См. [описание этапа 3](stage-3-pagination.md).

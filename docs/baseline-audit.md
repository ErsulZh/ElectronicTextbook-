# Исходное состояние проекта

Дата фиксации: 15.11.2026  
Проект: локальный сайт «Электронный учебник».

## Команды запуска и проверки

```powershell
npm ci
npm run check
.\start-site.bat
```

## Среда

| Компонент | Зафиксированное значение |
|---|---|
| Node.js | v26.13.0 |
| npm | 11.20.0 |
| Сервер | Node.js HTTP, только `127.0.0.1:4173` |
| Интерфейс | HTML/CSS/JavaScript + PageFlip + PDF.js |

## Состояние перед исправлениями

- `npm run check` проходит.
- `npm audit --omit=dev` сообщает 1 vulnerability уровня **high**: `pdfjs-dist` в уязвимом диапазоне `>=5.6.83 <6.2.108`.
- В папке `Тест` сохранены 20 пользовательских образцов; папка намеренно исключена из Git.
- Артефакты прежней Electron-версии (`dist/`, `main.js`, `preload.js`, `qa-book.png`, `qa-report.json`, `qa-source-docx/`) удалены после завершения перехода на локальный сайт. Они не нужны для запуска `start-site.bat`.
- Полный аудит до начала работ выявил, в частности, отсутствие очистки временных импортов, неполную поддержку ряда форматов, уязвимую версию PDF.js и ненадёжную обработку содержания/пагинации.

## Инвентаризация исходной корневой папки

| Объект | Роль |
|---|---|
| `server.js` | локальный HTTP-сервер и импорт документов |
| `src/` | интерфейс и логика книги |
| `start-site.bat` | запуск сайта для Windows |
| `package.json`, `package-lock.json` | зависимости Node.js |
| `Тест/` | пользовательские тестовые документы, не публикуются |
| `start-site.bat`, `server.js`, `package-lock.json`, `src/` | самодостаточный запуск локального сайта; `node_modules/` восстановит `npm ci` |

## Правило этапов

Изменения выполняются только после прохождения критериев готовности предыдущего этапа. После каждого этапа независимый контролёр проверяет diff, тесты и отсутствие побочных удалений.

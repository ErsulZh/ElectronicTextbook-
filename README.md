# Электронный учебник

Локальный сайт превращает учебные документы в книгу с содержанием, постраничной навигацией и эффектом перелистывания. Файлы обрабатываются только на `127.0.0.1`.

## Запуск

1. Установите Node.js 22.13+.
2. Запустите `start-site.bat` двойным щелчком. При первом запуске он сам выполнит `npm ci`.
3. Не закрывайте открывшееся окно командной строки во время чтения.

### Перенос на другой компьютер

Можно архивировать и перенести всю папку проекта. На другом компьютере распакуйте её, установите Node.js 22.13+ и запустите `start-site.bat`. Если в архив не добавлять папку `node_modules`, при первом запуске понадобится интернет: bat-файл сам установит зависимости. Microsoft Word нужен только для точного постраничного отображения Word-файлов; без него сайт всё равно открывает поддерживаемые документы в адаптированном виде.

## Поддержка форматов

| Формат | Статус | Что сохраняется | Зависимость/ограничение |
|---|---|---|---|
| PDF | Поддерживается | Страницы и встроенные bookmarks | Текст отображается как страница; поиск и выделение будут добавлены позже |
| DOCX / DOCM / DOTX | Поддерживается | При установленном Microsoft Word — исходная страница Word как отдельный лист книги: формулы, таблицы, рисунки и расположение сохраняются | Макросы никогда не запускаются; без Word включается адаптированный текстовый вид |
| DOC / DOT / DOTM / DOCB / RTF | Требует Microsoft Word | Исходная страница Word как отдельный лист книги | Нужен установленный Microsoft Word; макросы отключены |
| ODT | Ограниченно | Заголовки и абзацы | Таблицы, списки, изображения и сложные стили LibreOffice пока не переносятся |
| EPUB | Ограниченно | Порядок глав spine и текст глав | Оглавление, изображения, интерактивные элементы и сложные стили пока не переносятся |
| TXT | Поддерживается | Абзацы и UTF-8 / UTF-16LE / Windows-1251 | Форматирование в исходном TXT отсутствует |
| Markdown | Поддерживается | Заголовки, списки, выделение, ссылки и код | Внешние ссылки отключаются в режиме локального чтения |
| HTML | Ограниченно | Безопасные текстовые блоки, таблицы и локальные изображения | Скрипты, внешние ресурсы и стили документа удаляются |

Для Word точный режим сначала создаёт локальный PDF через Microsoft Word, а затем показывает его в книге. Поэтому одна страница исходного файла — это один лист книги: программа не меняет размер шрифта, не переносит формулы и не обрезает таблицы. Для навигации такой режим читает напечатанный блок «Мазмұны» / «Содержание» / «Оглавление» / «Contents» (включая `Table of contents`), а не технические закладки Word: автор, УДК и ISBN не становятся темами. На широком экране читатель показывает разворот из двух листов; на телефоне — один лист. Если в исходнике есть пустая страница, она сохраняется намеренно как часть оригинальной вёрстки.

## Проверки

```powershell
npm run check
npm run test:formats
npm run test:reader
npm audit --omit=dev
```

Документы из папки `Тест` используются только локально и намеренно не публикуются в Git.

Полный список проверенных рисков и честных ограничений находится в [дорожной карте аудита](docs/audit-roadmap.md).
